# AirMesh

_Crowdsourced, token-rewarded air quality sensing powered by Solana_

## Summary

AirMesh turns everyday phones and cheap sensors into a decentralized air-quality monitoring network. Contributors submit geotagged readings and earn token rewards validated through on-chain consensus, creating hyperlocal environmental data that's currently too expensive for cities to gather.

## Target users

Environmentally conscious citizens, city planners, researchers, and climate-tech startups

## Problem

Granular, real-time air quality data is scarce because centralized sensor networks are expensive to deploy and maintain at city scale.

## Solution

A mobile app plus lightweight Solana program lets anyone submit verified sensor readings, with rewards distributed based on data consistency and multi-source consensus.

## MVP features

- Mobile app for submitting geotagged, signed sensor readings
- Solana program distributing SPL token rewards based on consensus scoring
- Public map dashboard visualizing aggregated real-time air quality
- Staking mechanism to deter spam or fabricated data submissions
- Open API for third parties to query verified historical data

## Chains

Solana

## Tech

Anchor, React Native, Mapbox, Switchboard oracle, Arweave/IPFS storage, SPL Token

## Category

DePIN

## Why now

DePIN networks are scaling rapidly on Solana thanks to low fees that enable micro-reward loops, while demand for climate and environmental data is at an all-time high.

## Roadmap

- Partner with low-cost hardware sensor manufacturers for calibrated data
- Expand to additional data types like noise and traffic congestion
- Launch governance token and DAO for network parameter control
