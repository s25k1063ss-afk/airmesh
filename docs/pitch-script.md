# AirMesh — 1-minute pitch script

**0:00-0:15**

Air quality data is expensive to collect. Cities often rely on just a few sensors for the whole city. That means most neighborhoods have no real data at all. City planners, researchers, and climate startups need this data too.

> 大気質データの収集にはコストがかかります。多くの都市は、市全体でわずか数台のセンサーに頼っています。そのため、ほとんどの地域には実際のデータがありません。都市計画者や研究者、気候テック企業もこのデータを必要としています。

**0:15-0:30**

AirMesh fixes this. Anyone with a phone or cheap sensor can submit readings. Contributors earn token rewards on Solana for accurate data.

> AirMeshはこれを解決します。スマートフォンや安価なセンサーを持つ誰もが、測定データを送信できます。貢献者は、正確なデータに対してSolana上でトークン報酬を獲得します。

**0:30-0:45**

Readings are signed, stored on Arweave, and verified through consensus scoring. An Anchor program on Solana pays out SPL tokens automatically.

> 測定データは署名され、Arweaveに保存され、コンセンサススコアリングによって検証されます。Solana上のAnchorプログラムが、自動的にSPLトークンを支払います。

**0:45-1:00**

DePIN is growing fast on Solana because fees are so low. Next, we add hardware partners, new data types, and a DAO. AirMesh makes clean air data for everyone.

> Solanaは手数料が非常に低いため、DePINは急速に成長しています。次は、ハードウェアパートナーの追加、新しいデータ種類の拡充、そしてDAOの立ち上げを計画しています。AirMeshは、すべての人にきれいな空気のデータを届けます。
